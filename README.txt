USAGE

- Open logo-usage-guide.html in a web browser for the visual usage guide and
  direct links to every production asset in this package.
- Use the SVG files whenever possible. They are resolution-independent and
  contain no embedded raster images, live fonts, or external dependencies.
- Use the PNG files when SVG is not supported. All PNGs have transparent
  backgrounds; the pixel number in each filename is the image width.
- The “with-text” version is the primary horizontal identity for dark surfaces.
- The “with-text-light-background” version is the horizontal identity for
  letterhead, white paper, and other light surfaces.
- The “no-text” version is the standalone salamander mark.
- The “no-text-square” version centers the complete salamander on a square,
  transparent canvas for avatars, profile images, and square placements.
- The “no-text-with-trees-square” version combines the approved salamander and
  three-tree artwork on the same square, transparent canvas without lettering.
- favicon.ico contains 16, 32, 48, 64, 128, and 256-pixel icon sizes in one file.
- Preserve the artwork’s aspect ratio and do not stretch, skew, recolor, or
  rearrange individual elements.

SALAMANDER & TREE COLORS

- Salamander brown: #783100
- Salamander orange: #EF8F54
- Salamander eye: #C97F90
- Tree gradient: #C8DF97 to #8FBD3D

TEXT COLORS

- Primary text — light backgrounds: #4A220A
- Subtitle text — light backgrounds: #783100
- Primary text — dark backgrounds: #B4CF78
- Subtitle text — dark backgrounds: #B2B0AD

Modernized and repackaged in 2026 by Jason Lancaster. The salamander artwork

was smoothed while retaining the source eye and separated toe geometry. Text
was converted to vector outlines.
